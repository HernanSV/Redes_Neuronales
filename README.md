# Redes Neuronales
Comparación de modelos estadísticos y de redes neuronales interpretables en clasificación binaria.

Modelos considerados:

* Modelo Lineal Generalizado (MLG)
* Modelo Aditivo Generalizado (GAM) (librería `mgcv` de **R**)
* Red Neuronal Multicapa (MLP)
* Modelo Aditivo Neuronal (NAM) (Paquete `dnamite` para **Python**)
